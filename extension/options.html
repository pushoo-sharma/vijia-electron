Vijia Browser Bridge

Configure the local Electron bridge. The default bridge URL is http://127.0.0.1:45731.

Required. With Vijia running, open .vijia/browser-extension-bridge.json in your project folder (shown in the dev console as “Extension bridge config”), copy the sessionToken value, paste it here, and Save. If the badge shows SET, the token is missing; if OFF, URL or token does not match the app.
